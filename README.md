# Just Ask Aria — Homebrew tap

## Install Aria Links (one command)

```sh
curl -fsSL https://raw.githubusercontent.com/techytonys/homebrew-tap/main/install.sh | bash
```

That installs Homebrew first if your Mac doesn't have it, then installs
the Aria Links CLI. When it finishes, run:

```sh
aria-links login
```

Already have Homebrew? `brew install techytonys/tap/aria-links` does
the same job on its own.
